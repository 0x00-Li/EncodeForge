# EncodeForge 简体中文使用指南

## 启动

安装依赖后运行：

```bash
python main.py
```

首次启动需要配置 FFmpeg，可自动检测、自动下载或手动选择 `ffmpeg` 可执行文件。也可以使用 `python cli.py gui` 启动。

## 三个主要功能

1. **编码器**：添加文件或文件夹，选择容器、编码器、质量、预设和硬件加速，然后开始批量转码。
2. **字幕**：选择下载或 Whisper 本地生成，指定语言、字幕来源和输出格式。
3. **元数据**：扫描媒体后从在线来源匹配电影/剧集/动漫信息，先预览再批量改名。

## 整季重新切分

在“元数据”页面点击“整季重新切分…”，选择包含整季视频的目录并填写剧集名称和季号。程序会按文件名自然顺序连续合并视频，再重新编码为新的短剧集；默认每集在 30–50 秒之间随机，也可以把最短、最长时长设为相同数值以使用固定目标时长。程序优先遵守目标范围；如果会产生很短的最后一集，则先后尝试 5% 和 10% 的时长容差，将余量均摊到其他剧集。

源文件不会被修改。结果保存在所选目录下新建的剧集名称文件夹中，并按 `剧名 - S01E001.mp4` 命名。输出目录还会包含 `剧集介绍.md` 和 `poster.jpg`；海报优先使用在线元数据图片，无法获取时从视频抽帧生成。

生成目录内的 `.encodeforge-resplit-state.json` 会持续记录合并阶段、已完成集数和最新状态。过程中断后再次选择原目录或生成目录，程序会提示继续，并跳过已经完成的集数；有同名目录但没有状态文件时，为避免覆盖既有文件，程序会要求更换剧集名称。

也可以使用命令行：

```bash
python cli.py season-resplit ./整季目录 --title "剧集名称" --season 1
python cli.py season-resplit ./整季目录 --title "剧集名称" --min-seconds 45 --max-seconds 45 -y
```

左侧的“日志”和“进程”用于排错与观察后台任务；“设置”用于保存默认编码、字幕、命名和 API 参数。

## 中文/英文切换

程序默认显示简体中文。启动前设置环境变量即可切换英文：

```bash
ENCODEFORGE_LANG=en python main.py
```

汉化只影响界面文案，不会翻译 FFmpeg 编码器名称、字幕语言码（如 `eng`）或媒体文件名。

## 命令行改名

```bash
python cli.py rename ./媒体目录 --dry-run  # 仅预览
python cli.py rename ./媒体目录 -y         # 确认后执行
python cli.py rename ./媒体目录 -d ./整理后 --action move
```

建议先使用 `--dry-run` 检查匹配结果；程序会为实际改名生成备份记录，并可携带同名 `.srt`、`.ass`、`.nfo` 文件。
